# Mon Univers - Portfolio PWA

Un site portfolio personnel présentant mes passions et projets, maintenant disponible comme Progressive Web App (PWA).

## 🚀 Fonctionnalités PWA

- **📱 Installable** : Peut être installé sur mobile et desktop
- **🔄 Fonctionnement hors ligne** : Utilise un service worker pour la mise en cache
- **⚡ Chargement rapide** : Ressources mises en cache pour des performances optimales
- **🎨 Interface native** : Expérience similaire à une application native
- **🎯 Responsive** : Adapté à tous les types d'écrans

## 📋 Sections du portfolio

- **Mon Parcours** : Aperçu académique et professionnel
- **F1** : Passion pour la Formule 1 et l'innovation automobile
- **Voile** : Expérience de navigation et sport nautique
- **Projet Algue** : Recherche sur les bioplastiques durables
- **Cyber-Sécurité** : Solutions open-source pour la sécurité

## 🛠️ Installation locale

```bash
# Cloner le repository
git clone https://github.com/Damien-droid/joykoeur.git

# Aller dans le dossier
cd joykoeur

# Lancer un serveur local
python3 -m http.server 8000

# Ouvrir dans le navigateur
open http://localhost:8000
```

## 🎨 Technologies utilisées

- **HTML5** : Structure sémantique et accessibilité
- **CSS3** : Design responsive avec variables CSS
- **JavaScript (ES6+)** : Interactions et animations
- **PWA** : Service Worker, Web App Manifest
- **Icons** : FontAwesome et icônes PWA personnalisées

## 📱 Installation de l'app

Visitez le site dans votre navigateur et cliquez sur le bouton "Installer" qui apparaît en haut de la page pour ajouter l'application à votre écran d'accueil.
